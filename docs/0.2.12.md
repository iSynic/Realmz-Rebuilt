# Realmz Rebuilt 0.2.12

Realmz Rebuilt 0.2.12 fixes MP3 imports, overhauls the custom music workspace, and adds an optional Limit Monster Reinforcements adventure rule.

[Downloads for Windows, Linux, and macOS](https://github.com/iSynic/Realmz-Rebuilt/releases). Extract the complete archive and keep its importer and music-importer folders with the game. This release contains desktop builds only; no Android APK is included.

## Custom music

- **MP3 files import reliably.** Real-world MP3 files with ID3v2 tags or variable bitrates no longer fail import; the bundled music helper now validates MP3 streams directly through `libmpg123`.
- **Use classic Realmz's built-in tracks anywhere.** All eleven built-in Realmz tracks can now be added to custom playlists or assigned directly to any music context—so you can swap Indoor and Outdoor music in a couple of clicks without creating a playlist first.
- **Desert, Swamp, and Snow follow Outdoor automatically.** When those three terrain slots aren't assigned their own music, they automatically use whatever you assigned to Outdoor instead of reverting to stock music. You can still set any of them back to `Original music` or to its own track or playlist.
- **Clearer assignments, direct custom tracks, and previews.** Replaced confusing `Inherit` labels with `Original music`, `Use Outdoor`, `Use global default`, `Realmz track`, `Custom track`, and `Playlist`. `Custom track` lets you assign any individual imported track from your Library—or pick an individual track grouped under any playlist—without creating a wrapper playlist. Disabled rows show what actually plays for that context, the active context is marked, Wide column headers line up over their columns, switching sources immediately picks a valid target, and Preview/Stop controls are now available directly inside Playlists and Assignments.
- **Unsaved changes confirmation and tooltips.** Cancelling out of the music workspace with unapplied playlist, assignment, or mode edits now asks whether to keep editing, discard, or apply. Descriptive tooltips explain each tab, mode, and assignment option.
- **Larger folder imports and extensionless MOD files.** Batch imports now accept up to 256 files at a time, and folder imports check file headers so extensionless classic MOD/audio files import cleanly while non-audio files in the same folder are skipped.

## Adventure rules

- **Limit Monster Reinforcements** (Settings, Adventure Rules; also reachable from party setup). Many battles roll each round to call in more monsters, and classic Realmz never stops them. You can now cap how many rounds of a battle may bring in reinforcements (`Classic (unlimited)` by default, or `Off (no reinforcements)`, `1 wave`, `2 waves`, `3 waves`, or `5 waves`). Monsters summoned directly by a creature or spawned on death are unaffected.

## Saves

**0.2.12 writes the same save v9 as 0.2.11 and reads v5–v9.** 0.2.11 and earlier can't open a save with Limit Monster Reinforcements set to anything other than `Classic (unlimited)`. Beta 27 can't read v9, so keep an untouched v8-or-earlier save if you want to be able to go back to it.

The 0.2.10 caution still applies: don't take a save with opened dungeon walls back to 0.2.9 or earlier and forward again.

No bundled scenario or the application library changed, so you don't need to reimport anything.

All versions use the same local data folder, so extracting another copy of the game doesn't give it separate saves or Character Files. Back up saves and characters you care about before upgrading.

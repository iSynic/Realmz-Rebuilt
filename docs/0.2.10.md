# Realmz Rebuilt 0.2.10

Realmz Rebuilt 0.2.10 fixes five reported problems, most of them in 3D dungeons.

[Downloads for Windows, Linux, and macOS](https://github.com/iSynic/Realmz-Rebuilt/releases). Extract the complete archive and keep its importer and music-importer folders with the game. This release contains desktop builds only; no Android APK is included.

## Dungeons

- **Walls that an event opens now open** (issue #50). When a scenario changed a tile inside a dungeon, the game changed the wrong cell and did not rebuild the one it changed. The wall the event described stayed shut, and a false opening could appear elsewhere that you could not walk through. Reported in the temple under Tanirith in War in the Sword Lands; it affected every dungeon tile change in every scenario.
- **Existing saves are repaired when you load them.** Walls that should already have opened are open, and the false openings are walls again.
- **Hidden passages are found as you walk beside them** (issue #49). As in the original, each step in a dungeon checks the eight cells around the party. Search mode and Discover Secret make the check certain; otherwise it uses the party's Detect Secret skill. With Search mode on, each dungeon step also takes the extra search time it already took on land.

## Combat

- **Turn Undead plays much faster** (issue #47). It now uses the same short timings as a spell with many targets, and every undead that resists shows "Resist" at the same moment instead of one after another. Against twenty undead it takes under a third of the time it did. With Condense Multi-Target Playback on (Settings, Pacing), all the undead from one attempt show their results together.
- **The combat text preview shows the real size** (issue #46). The sample in Settings, Pacing is now drawn at the scale of the battlefield, so the text size you choose looks the same in the preview and in battle. The preview is taller at higher world zoom.

## Interface

- **The facts line holds still while the party rests** (issue #48). Fatigue, the clock and light keep a fixed width, so only the numbers and the fatigue meter change.
- **A party of six fits the Modular HUD roster.** At the default size the sixth character was cut off and the roster had to be scrolled. The roster is now as tall as its party in every interface theme.

## Saves

**0.2.10 writes the same save v9 as 0.2.9 and reads v5–v9.** Beta 27 can't read v9, so keep an untouched v8-or-earlier save if you want to be able to go back to it.

Saves written by 0.2.10 carry a mark that their dungeon changes are stored correctly. 0.2.9 and earlier can still open them, but saving there removes the mark, and 0.2.10 would then repair that save a second time and misplace its opened dungeon walls. Don't take a save with opened dungeon walls back to an earlier version and forward again.

No bundled scenario or the application library changed, so you don't need to reimport anything.

All versions use the same local data folder, so extracting another copy of the game doesn't give it separate saves or Character Files. Back up saves and characters you care about before upgrading.

## Reporting problems

Use the [bug report form](https://github.com/iSynic/Realmz-Rebuilt/issues/new?template=beta_bug.yml). Include the version, operating system, scenario, exact steps, and an original save from before the problem when possible. Check attachments for private information before sharing them.

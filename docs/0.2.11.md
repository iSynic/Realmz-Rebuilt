# Realmz Rebuilt 0.2.11

Realmz Rebuilt 0.2.11 fixes items that clashed when characters from earlier adventures joined a new one.

[Downloads for Windows, Linux, and macOS](https://github.com/iSynic/Realmz-Rebuilt/releases). Extract the complete archive and keep its importer and music-importer folders with the game. This release contains desktop builds only; no Android APK is included.

## Items

- **Every item a party carries stays its own item.** Each adventure numbered the items it handed out from one again, while Character Files keep their items from earlier adventures. A purchase or reward could therefore get the same identity as an item a character already carried. Choosing or equipping the new item could then pick the old one instead, and the adventure could no longer be saved. New items now skip any identity the party already holds.
- **Characters with clashing items can join the same party.** Two Character Files that had each bought or found items in different adventures could be refused at party setup with "could not be added to the party". The joining character's clashing items now take fresh identities and stay equipped. This applies in party setup, when importing a saved party, and when adding a character in the save editor.
- **A battle reward no longer fails when a fumbled weapon is among the loot.** A fumbled weapon could hold the identity the next reward item was about to take, and the reward failed to open.

## Saves

**0.2.11 writes the same save v9 as 0.2.10 and reads v5–v9.** Beta 27 can't read v9, so keep an untouched v8-or-earlier save if you want to be able to go back to it.

The 0.2.10 caution still applies: don't take a save with opened dungeon walls back to 0.2.9 or earlier and forward again.

No bundled scenario or the application library changed, so you don't need to reimport anything.

All versions use the same local data folder, so extracting another copy of the game doesn't give it separate saves or Character Files. Back up saves and characters you care about before upgrading.

## Reporting problems

Use the [bug report form](https://github.com/iSynic/Realmz-Rebuilt/issues/new?template=beta_bug.yml). Include the version, operating system, scenario, exact steps, and an original save from before the problem when possible. Check attachments for private information before sharing them.

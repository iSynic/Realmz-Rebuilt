# Realmz Rebuilt 0.2.5

Realmz Rebuilt 0.2.5 lets you leave a required ally behind after battle, moves money at classic Realmz speed with an optional faster setting, adds an Allies button to the Party footer, and makes Treasure easier to use with a controller.

[Downloads for Windows, Linux, and macOS](https://github.com/iSynic/Realmz-Rebuilt/releases). Extract the complete archive and keep its importer and music-importer folders with the game. This release contains desktop builds only; no Android APK is included.

## Fixes

- **You can leave a required ally behind after battle** ([#41](https://github.com/iSynic/Realmz-Rebuilt/issues/41)). As in classic Realmz, allies the scenario needs start out selected, and you can still untick one after the warning that it may be important. This fixes the Daneel lockout.
- **Money moves at classic Realmz speed** ([#40](https://github.com/iSynic/Realmz-Rebuilt/issues/40)). Party Wealth, Shop Money, the bank, leaving town and Treasure Money move one step per tap. Hold the button and it keeps going, one step per frame. The selected adventurer stays selected through transfers, Pool and Share, and post-battle Treasure Money no longer jumps back to the first adventurer.
- **Treasure works with a controller.** You can reach every Money and Drop control. Drop menus open, scroll and confirm with the d-pad. Closing Treasure Money puts you back on the Money button.
- **The d-pad stays where you point it.** Moving focus goes to the nearest control in that direction, or one in the same row or column. At an edge, focus stays put instead of jumping across the screen.
- **Treasure Drop works like classic Realmz.** The Drop menu lists everything a character carries. If you pick a worn cursed item, you hear the drop sound and get the cursed warning, and the item stays on. A dropped item is gone; it doesn't go back into the loot.

## Changes

- **Money Transfer Speed.** A new Adventure Rule sets how much each money step moves, from classic speed (1x) up to 5x. Each step still stops at what the character has and what they can carry. Find it in party setup or in Settings under Adventure Rules.
- **An Allies button on the Party footer.** It shows the battle icons of the first three allies traveling with you. With no allies along, it stays visible but disabled.

## Saves

**0.2.5 writes the same save v9 as 0.2.4 and reads v5–v9.** 0.2.4 and earlier can't open a save with Money Transfer Speed above 1x. Beta 27 can't read v9, so keep an untouched v8-or-earlier save if you want to be able to go back to it.

No bundled scenario, the application library or Character Files v2 changed, so you don't need to reimport anything.

All versions use the same local data folder, so extracting another copy of the game doesn't give it separate saves or Character Files. Back up saves and characters you care about before upgrading.

## Reporting problems

Use the [bug report form](https://github.com/iSynic/Realmz-Rebuilt/issues/new?template=beta_bug.yml). Include the version, operating system, scenario, exact steps, and an original save from before the problem when possible. Check attachments for private information before sharing them.

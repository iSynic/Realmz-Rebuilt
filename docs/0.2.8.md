# Realmz Rebuilt 0.2.8

Realmz Rebuilt 0.2.8 shows the messages classic Realmz shows before a battle, gives every screen a new look with interface themes, and adds a save editor, a character editor and a much fuller modular HUD.

[Downloads for Windows, Linux, and macOS](https://github.com/iSynic/Realmz-Rebuilt/releases). Extract the complete archive and keep its importer and music-importer folders with the game. This release contains desktop builds only; no Android APK is included.

## Fixes

- **Messages before a battle are shown again** ([#45](https://github.com/iSynic/Realmz-Rebuilt/issues/45)). A scripted fight now stops on its story text and waits for a click or key, then on the battle's own opening line, and only then starts, as in classic Realmz. Random encounters wait on their opening line the same way. You can take a journal note from these messages.
- **Timed conditions clear when a party member falls**, in and out of combat.
- **Preparing a scenario waits for the stock library**, so a quick start can no longer race it.
- **The main menu no longer freezes for several seconds** just after it appears.

## New

- **Interface themes.** Choose a theme in Settings. Menus, the play screen, combat and shops take its colours and frame, with an optional faint texture on panels (on by default at 25%). A new or reset profile starts with Slate Bone; existing settings keep the look they had.
- **Save editor** and a **Character Files character editor**.
- **Redesigned screens:** Settings, party setup, Character Files, Inventory, the character sheet, Party Wealth, the spellbook, the Bestiary and Allies, Maps & Notes, Save & Load, the Shop, Victory Spoils, the level result, temple and bank.
- **Change equipment in shops.** Equip a purchase straight away, or unequip something so you can sell it.
- **Edge glow when the party is harmed.** The window edge glows red when a party member loses stamina, green for poison and ochre for disease. Turn it off in Settings > Accessibility; Reduced motion makes it fainter and steady.
- **Castle's fumble warnings**, legal area centres and rejection reasons for learned spells, and marked legal targets for touch players.
- **Interface sounds** and themed tooltips.

## Modular HUD

The fixed HUD is still the default. Switching to the modular HUD in Settings now starts from a ready-made arrangement for the map and for combat.

- **Combat:** the battlefield fills the window, with the command groups, turn order and active combatant as movable pieces. Ctrl+drag moves a piece, right-click sizes or resets it, and the turn order can run vertically along a side.
- **Party dock:** stamina and spell-point bars shade as they run low and follow each blow during combat playback.
- **Combat Log:** cleaner layout, a filter by combatant, a movement toggle and adjustable text size.
- Each panel can be sized on its own.

## Party import

- Identical scenario items carry across adventures, and changed versions are offered.
- Campaign-only items join an import when the destination defines them; otherwise the import explains why they stay behind.
- Character Files and party import open faster.

## Saves

**0.2.8 writes the same save v9 as 0.2.7 and reads v5–v9.** Beta 27 can't read v9, so keep an untouched v8-or-earlier save if you want to be able to go back to it.

A save taken while a message before a battle is on screen can't be opened by 0.2.7 or earlier. Click through the message before saving if you might go back.

No bundled scenario or the application library changed, so you don't need to reimport anything.

All versions use the same local data folder, so extracting another copy of the game doesn't give it separate saves or Character Files. Back up saves and characters you care about before upgrading.

## Reporting problems

Use the [bug report form](https://github.com/iSynic/Realmz-Rebuilt/issues/new?template=beta_bug.yml). Include the version, operating system, scenario, exact steps, and an original save from before the problem when possible. Check attachments for private information before sharing them.

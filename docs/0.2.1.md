# Realmz Rebuilt 0.2.1

Realmz Rebuilt 0.2.1 fixes the problems you reported in 0.2.0, including loading a backup, slow money changing, getting trapped in the ice dragon's cave and weapon immunities that never said why. It also brings a few more rules in line with classic Realmz and adds an optional rule that lets Bards use daggers.

[Downloads for Windows, Linux, and macOS](https://github.com/iSynic/Realmz-Rebuilt/releases). Extract the complete archive and keep its importer and music-importer folders with the game. This release contains desktop builds only; no Android APK is included.

## Fixes

- **Loading a save takes you back to your adventure** ([#32](https://github.com/iSynic/Realmz-Rebuilt/issues/32)). A successful load used to leave Save & Load open with no visible message, so it looked like nothing had happened. Now you're returned to the game. If a load fails, the reason appears on the Save & Load screen.
- **Holding a money button speeds up** ([#31](https://github.com/iSynic/Realmz-Rebuilt/issues/31)). Keep holding and it changes ten units at a time after about three seconds, then a hundred after about eight, at the same rates. You can now press and hold these buttons with a controller too.
- **No more getting stuck in the ice dragon's cave** ([#33](https://github.com/iSynic/Realmz-Rebuilt/issues/33)). Some scenarios use a Code 13 step to turn Action Point 0 on or off. In classic Realmz that step does nothing, so in Trouble in the Sword Lands the cave's Action Point stayed active after Icingbreath died and could trap you behind it. Rebuilt now carries out those steps in every scenario. If you're already stuck, cast Discover Secret, step back onto the Action Point and fight again. That runs the step and lets you out.
- **Dungeon Action Point ranges now work.** Authors wrote dungeon ranges as negative numbers, like -39 to -47, and classic Realmz never ran them. Rebuilt runs them by record number and still makes every change Castle made. In Trouble in the Sword Lands, the temple's rooms reset when you leave and come back, the way their author set them up. Some traps and ambushes in War in the Sword Lands and Wrath of the Mind Lords now arm the way their authors wrote them.
- **Blocked hits say what weapon you need** ([#34](https://github.com/iSynic/Realmz-Rebuilt/issues/34)). A monster that needs a particular weapon used to show "Miss" or "Blocked." Now you get Castle's wording: Need Blunt Weapon, Need Sharp Weapon, Need Special Weapon or Need Stronger Magic!. That includes attacks by your allies and summons.
- **Monsters fight each other the way they do in Castle.** A monster with no weapon gets past blunt and sharp requirements. A monster whose weapon can't hurt its target drops it, and you'll see "Creature Disarms."
- **Item descriptions only list classes that can use the item** ([#30](https://github.com/iSynic/Realmz-Rebuilt/issues/30)). Fang's description said Bards could use it, but in Classic Realmz Bards can't use daggers at all. "Usable only by" now lists only classes that can actually equip the item.
- **Poisoned Sickle is usable in Half Truth.** It was meant for Enchanters, Evokers and Warlocks, but none of them could equip it. Now they can.
- **New combat text defaults** ([#35](https://github.com/iSynic/Realmz-Rebuilt/issues/35)). New and reset settings show combat text at 150% speed and 85% size, centered on the icon, with no background. Settings you've already saved stay the same.

## New: Bard daggers

Turn on **Settings > Adventure Rules > Bard daggers** if you'd like Bards to be able to equip and use daggers, Fang included. The item's other limits still apply, and it doesn't affect a scenario's own Bard class. It's off by default and saved with each adventure. If you turn it off later, a Bard keeps a dagger that's already equipped but can't equip it again after taking it off.

## Saves

**0.2.1 writes save v9 and reads v5–v9, just like 0.2.0.** 0.2.0 can open your 0.2.1 saves, except saves from an adventure with Bard daggers turned on. Beta 27 can't read v9, so keep an untouched v8-or-earlier save if you want to be able to go back to it.

The Code 13 fixes affect only the steps that run after you update. Your saves keep everything that has already happened. Character Files v2, the application library, the bundled scenario archives and the package formats haven't changed, so you don't need to reimport anything or use Update Save.

All versions use the same local data folder, so extracting another copy of the game doesn't give it separate saves or Character Files. Back up saves and characters you care about before upgrading.

## Reporting problems

Use the [bug report form](https://github.com/iSynic/Realmz-Rebuilt/issues/new?template=beta_bug.yml). Include the version, operating system, scenario, exact steps, and an original save from before the problem when possible. Check attachments for private information before sharing them.

## Known limitations

The Code 13 fixes change how some authored routes play across the bundled and imported scenarios, and we haven't played through every route they affect. If a scenario now behaves differently from what you remember, please report it.

The intermittent combat spellbook-input issue remains unresolved. Power Level, Choose Targets and Abort can sometimes stop responding while Back to battle still works. Returning to battle and reopening Spells may help.

The optional modular HUD is still a work in progress, and the fixed HUD remains the default.

# Realmz Rebuilt 0.2.9

Realmz Rebuilt 0.2.9 makes the main menu usable much sooner after launch.

[Downloads for Windows, Linux, and macOS](https://github.com/iSynic/Realmz-Rebuilt/releases). Extract the complete archive and keep its importer and music-importer folders with the game. This release contains desktop builds only; no Android APK is included.

## Faster start

- **The pause after the main menu appears is much shorter.** The game used to build every screen at launch, which froze the menu for several seconds. Screens most sessions never open are now built the first time you use them: the save editor, the music workspace's assignment rows, and the file browsers for music, character art, fonts and party import.
- **The main menu takes your choice straight away.** Scenario, Load saved adventure, Character Files and Settings no longer wait greyed out. If you choose one while the game is still finishing its start-up, the hint line reads "Finishing startup…" and your choice opens as soon as it can.
- The first time you open the save editor in a session there is a brief pause while it is built.

## Fixes

- **Symbols show in the browser build.** The tick beside the selected scenario, the controller radial menu's symbols and other interface symbols appeared as empty boxes when the game ran in a browser, which has no system fonts to borrow them from. The game now carries its own symbol fonts for that case. Desktop builds are unchanged.
- **The held-save notice in Saved Adventures clears properly** when no campaign is selected. A new profile could leave it in a bad state.

## Saves

**0.2.9 writes the same save v9 as 0.2.8 and reads v5–v9.** Beta 27 can't read v9, so keep an untouched v8-or-earlier save if you want to be able to go back to it.

No bundled scenario or the application library changed, so you don't need to reimport anything.

All versions use the same local data folder, so extracting another copy of the game doesn't give it separate saves or Character Files. Back up saves and characters you care about before upgrading.

## Reporting problems

Use the [bug report form](https://github.com/iSynic/Realmz-Rebuilt/issues/new?template=beta_bug.yml). Include the version, operating system, scenario, exact steps, and an original save from before the problem when possible. Check attachments for private information before sharing them.

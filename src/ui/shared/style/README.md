# Shared style and controls

This folder contains the small scene and script vocabulary reused throughout the interface: Classic bitmap buttons, exact content icons, typography, the shared theme, scroll-arrow binding, and the Wide/Compact layout profile.

These components receive already-decided labels, media, availability, and layout mode. They do not know which route is open or recalculate gameplay facts. Open a feature scene to change its composition; change this folder only when the same visual contract genuinely belongs to several features.

# Realmz Rebuilt 0.2.7

Realmz Rebuilt 0.2.7 fixes the War in the Sword Lands first battle freezing, and makes Treasure, camping and choosing a campaign faster.

[Downloads for Windows, Linux, and macOS](https://github.com/iSynic/Realmz-Rebuilt/releases). Extract the complete archive and keep its importer and music-importer folders with the game. This release contains desktop builds only; no Android APK is included.

## Fixes

- **War in the Sword Lands no longer freezes in its first battle** ([#43](https://github.com/iSynic/Realmz-Rebuilt/issues/43)). Reinforcements arrive where a fallen monster stood, as in classic Realmz, and new monsters appear as soon as they join the battle.
- **Auto and monsters stop draining their own spell points** with Power Surge and similar spells that cost more than they restore. Manual casting is unchanged.
- **A controller no longer drives the game while another application has focus.**

## Faster

- Taking items in Treasure, and Camp, Rest and Heal on the map, respond noticeably faster.
- Choosing a bundled campaign starts sooner.

## Saves

**0.2.7 writes the same save v9 as 0.2.6 and reads v5–v9.** Beta 27 can't read v9, so keep an untouched v8-or-earlier save if you want to be able to go back to it.

No bundled scenario, the application library or Character Files v2 changed, so you don't need to reimport anything.

All versions use the same local data folder, so extracting another copy of the game doesn't give it separate saves or Character Files. Back up saves and characters you care about before upgrading.

## Reporting problems

Use the [bug report form](https://github.com/iSynic/Realmz-Rebuilt/issues/new?template=beta_bug.yml). Include the version, operating system, scenario, exact steps, and an original save from before the problem when possible. Check attachments for private information before sharing them.
